# Школа маркетри Татьяны Гориной — сайт

Статический сайт (HTML + CSS + немного JS), сборка не нужна. Подходит для любого российского хостинга (Beget, Timeweb, REG.RU): загрузить содержимое папки в корень сайта.

## Страницы
- index.html — главная
- obuchenie.html — курс из трёх этапов
- master.html — о мастере
- galereya.html — галерея (работы мастера и учеников)
- zhurnal.html — журнал и 5 статей: marketri-istoriya-i-tehnika, kak-nauchitsya-marketri, porody-shpona-dlya-marketri, instrumenty-dlya-marketri, uhod-za-izdeliyami-iz-shpona
- kontakty.html — контакты
- politika.html — политика конфиденциальности (cookie, Яндекс Метрика)
- 404.html — страница «не найдено»

## Что заменить перед запуском
1. **Домен.** Везде стоит `https://example.ru` (canonical, Open Graph, микроразметка, sitemap.xml, robots.txt). Заменить на настоящий одной командой поиска и замены.
2. **Контакты.** Телефон `+7 (900) 000-00-00`, почта `info@example.ru`, Telegram `t.me/username`, WhatsApp `wa.me/79000000000`, MAX `max.ru/username` — во всех HTML-файлах. Адрес уже указан: Москва, Брошевский переулок, дом 4.
3. **Фото.** Все картинки в `img/*.svg` — заглушки с подписью «МЕСТО ДЛЯ ФОТО»:
   - `hero.webp` / `hero.jpg` — иллюстрация на первом экране (композиция работ в технике маркетри, 1200×1500). При желании заменить на фото работ мастера той же пропорции 4:5
   - `tatyana-gorina.webp` / `.jpg` — портрет мастера (4:5), уже стоит
   - `process.svg` — фото процесса для статьи (3:2)
   - галерея по рубрикам: `panno-1…3`, `mebel-1…3`, `shkatulki-1…3`, `shahmaty-1…3`, `interer-1…3`, `portrety-1…3`, `dekor-1…3` (.svg); работы учеников — `s01–s06.svg`. В галерее фото обрезаются до пропорции 4:5
   Фото заменить на JPG/WebP шириной 1600 px и обновить имя файла и атрибуты width/height в HTML.
4. **Тексты-заглушки** выделены серым блоком с полосой слева (класс `placeholder`): «как добраться», данные владельца в политике. Рассказ мастера (master.html) написан по интервью из книги, стоит показать Татьяне на согласование. Длительность этапов и стоимость курса — «Уточняется».
5. **Подписи в галерее**: у работ мастера «Название работы / Породы шпона, размер», у учеников «Имя ученика / Этап курса, название работы».
6. **Карта.** На странице контактов стоит Яндекс Карта по адресу. При желании заменить на карту из конструктора Яндекс Карт с меткой.

## SEO и аналитика
- У каждой страницы свои title, description, canonical и Open Graph; картинка для превью — `img/og.jpg`.
- Микроразметка schema.org: EducationalOrganization, WebSite, FAQPage, Course, Person, Article, BreadcrumbList.
- `sitemap.xml`, `robots.txt`, иконки, `site.webmanifest`, `.htaccess` (HTTPS, без www, сжатие, кэш, 404).
- **Яндекс Метрика:** код счётчика вставить в `<head>` всех страниц на место комментария «Яндекс Метрика». Включить Вебвизор по желанию.
- **Яндекс Вебмастер:** раскомментировать meta `yandex-verification` с кодом, добавить sitemap.
- Шрифты Spectral и Golos Text подключены через Google Fonts.

## Режим показа клиенту
Сейчас сайт скрыт от поисковиков: на всех страницах `<meta name="robots" content="noindex">`, в `robots.txt` стоит `Disallow: /`. Перед запуском на настоящем домене вернуть индексацию (в скрипте сборки `PREVIEW = False`).

## Языки
- Русская версия — в корне сайта, английская — в папке `en/` (те же имена файлов). Переключатель RU/EN в шапке ведёт на ту же страницу на другом языке; в `<head>` прописаны `hreflang`.
- Английские страницы собираются из русских по словарю переводов: `tools/i18n.py` + `tools/en_map.py`.
- Порядок после правки текстов: `python3 tools/build.py` → `python3 tools/i18n.py extract` → дописать перевод новых фрагментов в `tools/en_map.py` → `python3 tools/i18n.py build`. Скрипт предупредит, если на английских страницах осталась кириллица.

## Навигация
- Новая страница всегда открывается с начала; при возврате (кнопка «Назад» на сайте или в браузере) страница встаёт на то место, откуда ушли.
- На внутренних страницах есть кнопка «Назад», на длинных — кнопка «Наверх».
